# 42 Tokyo BSQ 全体像

### `<main>`

* `argc`が1の場合は標準入力（`fd = 0`）を処理し、2以上の場合は引数として与えられた各ファイルを順次処理する。 
* ファイルのオープンに失敗した場合は "map error\n" を**標準出力（1）**に書き込む。
* 2つ目以降の出力（結果またはエラー）の前に必ず空行（`\n`）を挿入する。
* 正常にオープンできた `fd` のみ、処理後に `close` する。
* `process` 関数を介して、読み込み、解析、解決、表示、メモリ解放のサイクルを実行する。

### `<process>`

* `read_file` で取得したコンテンツが `NULL`、または `parse_map` に失敗した場合は "map error\n" を表示して終了する。 
* `solve` 関数の戻り値をチェックし、メモリ確保失敗などで `0` が返った場合も "map error\n" を表示する。
* 正常系では `solve` で正方形を特定し、`print_map` で結果を出力した後、`free_map` でメモリを完全に解放する。

### `<read_file>`

* `read` システムコールを用いて、ファイルを動的に確保したメモリに読み込む。 
* `read_loop` 内で4096バイトずつのバッファを使用し、`read` が `0`（EOF）を返すまで読み込みを繰り返す。
* 読み取りに失敗した場合は確保済みのメモリを解放し `NULL` を返す。

### `<append_chunk>`

* 現在のバッファ `buf` と新しく読み込んだデータを結合するため、新たなサイズのメモリを `malloc` する。 
* 既存のデータと新データを順にコピーし、最後に `\0` を付与して古いバッファを `free` する。 

### `<parse_map>`

* `t_map` 構造体を確保し、ヘッダー（1行目）から情報を抽出する。
* `build_grid` を呼び出してマップの2次元配列を構築する。
* 解析の過程で「行数不一致」「不正文字」「余剰データ」が検知された場合はエラー（`NULL`）を返す。

### `<parse_header>`

* 1行目の末尾3文字（empty, obstacle, full）を抽出し、それらが全て表示可能文字（printable）であることを確認する。
* 3文字のキャラクターに重複がないこと、および数字でないことを判定する。
* 行数（`rows`）を数値として解析し、正の整数であることを保証する。 
* ヘッダーが適切な改行（`\n`）で終了していない場合は無効とする。

### `<build_grid>`

* `map->rows` 分の配列を `malloc` し、ヘッダー直後の改行からデータの解析を開始する。 
* `fill_grid` から返されたポインタが文字列の終端（`\0`）でない場合、「宣言行数以降の余剰データ」としてエラーにする。

### `<fill_grid>`

* 各行を走査し、すべての行がヘッダーで確定した `map->cols` と同じ長さであることを検証する。 
* 各行の末尾が必ず改行文字（`\n`）で区切られていることを確認する。
* 読み終わった位置のポインタを返し、余剰データの判定に利用する。
* 行の長さの不一致や不適切な文字、改行不足がある場合は `free_partial` で解放して終了する。 

### `<fill_row>`

* 1行分のメモリを確保し、中身がヘッダーで定義された「空きマス」か「障害物」のいずれかであることを確認しながらコピーする。 
* 定義されていない不正な文字が含まれる場合は `0` を返す。 

### `<solve>`

* 動的計算用のテーブル `dp` を `alloc_dp` で確保する。 
* 全てのマスに対して `run_dp` を実行し、見つかった最大正方形のサイズと右下座標を特定する。
* 複数の解がある場合、マップの最も「上」、次いで「左」にある正方形を選択する。 
* 最後に `fill_square` を呼び出して、元のグリッドに正方形を描画する。

### `<calc_dp>`

* 現在のマスが「障害物」なら 0 を返す。
* マスが上端（`r=0`）または左端（`c=0`）なら 1 を返す。
* それ以外の場合、**「上」「左」「左上」の3つのマスの最小値に 1 を加えた値**を算出し、動的計画法（DP）により最大正方形の辺の長さを求める。

### `<fill_square>`

* 特定された最大サイズと座標から逆算し、該当範囲の文字を `map->full` に書き換える。 

### `<print_map>`

* `write` システムコールを用い、グリッドを 1 文字ずつ出力して各行末に改行を挿入する。 

### `<free_map>` / `<free_partial>`

* マップ構造体、グリッド、DP計算用配列を、行ごとに `free` してから親ポインタを `free` する。 
* 正常終了時だけでなく、エラー中断時にもメモリリークが発生しないよう設計されている。
